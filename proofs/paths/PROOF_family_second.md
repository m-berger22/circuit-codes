# The second-step family fam(n) is a spread-(6n+3) path of length 26n+20: proof for all n >= 1  (S179)

**Theorem.** Let n >= 1, K = 6n+4, k = K-1 = 6n+3, d = 10n+7, and let T = fam(n) = P0 P1 P2 P3 P4 (pfam3.py; Section 1),
a word of length L = 4K + 2n+4 = 26n+20 over d coordinates. Then T is the transition word of a spread-k path in Q_d:
for all 0 <= s <= p <= L, with odd[s,p) = number of coordinates occurring an odd number of times in T[s..p-1]
(= d_H(v_s, v_p)),

    p - s < k   implies   odd[s,p) = p - s,          p - s >= k   implies   odd[s,p) >= k.

Status: **complete for all n >= 1, no separate small cases** (n0 = 1; Section 7 lists exactly what kind of evidence
each step has). Every numbered statement, every table entry and every case inequality is brute-force tested against the
words for n = 1..10 (Section 9 says by which script); the case tables of Section 5 are in addition verified for ALL n
in exact arithmetic (certificates).

Proof idea (same method as PROOF_family_excess.md, the sister family). The five cut vertices v_0, v_K, .., v_4K
form a NEAR-simplex: pairwise distance K, except d_H(v_0, v_4K) = K+2. A vertex inside piece j is v_jK plus a prefix of
P_j, so the distance between two vertices in different pieces is D_jj' plus a signed count over the symmetric
difference of two prefixes (Near-Simplex Lemma). Each prefix is described by explicit index sets (State Table). For
ADJACENT pieces (including P3 and the tail) everything follows from one injection (Slot Lemma). For NON-ADJACENT
pieces (including the pairs (P_j, tail), j = 0, 1, 2) the claim is S >= -1 (S >= -3 for the pair (P0, tail), where
D = K+2) for an explicit signed sum S; it is checked zone pair by zone pair (36 zone pairs). Differences to the sister
proof: the tail is a full fifth piece P4 of length 2n+4; the zones have lengths 2n+2, 2n+2, 2n; and the case tables of
Section 5 were not written by hand but GENERATED by exact symbolic case splitting (derive.py), each case with a
one-line certificate that can be checked by hand and is re-checked in rational arithmetic (test_cert.py).

## 2. The Near-Simplex Lemma

A type tau **separates** j and j' if exactly one of j, j' lies in tau. Put sigma_{jj'}(tau) = -1 if tau separates
j, j' and +1 otherwise; sigma(c) = sigma(type of c) for a coordinate c.

Vertices: every position 0 <= p <= L is uniquely p = jK + e with (0 <= j <= 3 and 0 <= e < K) or (j = 4 and
0 <= e <= 2n+4). Write Pre_j(e) = set of the first e letters of P_j (e distinct coordinates by (P)).

**Near-Simplex Lemma.** Let p = jK+e and p' = j'K+e' with j < j'. Then

    odd[p,p') = d_H(v_p, v_p') = D_jj' + S_{jj'}(e,e'),     S_{jj'}(e,e') := sum over c in Pre_j(e) symdiff Pre_j'(e') of sigma_{jj'}(c),

    where D_04 = K+2 and D_jj' = K for all other pairs.

*Proof.* Identify vertices with sets of coordinates. By (P), v_{(j+1)K} = v_{jK} xor {tau_i : [j in tau] != [j+1 in tau]}
for j = 0..3, so by induction v_{jK} = v_0 xor {tau_i : [0 in tau] != [j in tau]} for j = 0..4, hence

    v_{jK} xor v_{j'K} = Dset_{jj'} := {tau_i : tau separates j, j'}.

Six types separate j, j' (the types {j,w}, {j',w} with w one of the other three elements). For {j,j'} = {0,4} these are
01, 02, 03, 14, 24, 34: all big, 6(n+1) = K+2 coordinates. For every other pair exactly two of the six are small
((0,1): 12,13; (0,2): 12,23; (0,3): 13,23; (1,2): 13,23; (1,3): 12,23; (2,3): 12,13; (1,4): 12,13; (2,4): 12,23;
(3,4): 13,23), so there are 4(n+1) + 2n = K coordinates. Now v_p = v_{jK} xor X1, v_p' = v_{j'K} xor X2 with
X1 = Pre_j(e), X2 = Pre_j'(e'), so v_p xor v_p' = Dset xor X with X = X1 symdiff X2 and
|Dset xor X| = |Dset| + #{c in X : c not in Dset} - #{c in X : c in Dset}. QED   [test_simplex.py]

**Per-type form.** For a type tau let I_j,tau(e) = {i : tau_i in Pre_j(e)} (empty if tau does not occur in P_j). Then

    (S)   S_{jj'}(e,e') = sum over the types tau of  sigma_{jj'}(tau) * n_tau,     n_tau = | I_j,tau(e) symdiff I_j',tau(e') |.

If tau occurs only in P_j we write u_tau for n_tau (= |I_j,tau(e)|), if only in P_j' we write w_tau (= |I_j',tau(e')|).

## 4. Adjacent pieces: the Slot Lemma

Let 0 <= j <= 3 and consider a window from offset e of P_j (0 <= e < K) to offset e' of P_{j+1} (0 <= e' < K; for
j = 3: 0 <= e' <= 2n+4). Its length is w = K - e + e'. A coordinate c occurring in both pieces ("common letter")
occurs once in each (by (P)), at offsets p_c in P_j and q_c in P_{j+1}. So the coordinates occurring twice in the
window are the common letters with p_c >= e and q_c < e', all others occur at most once, and

    (A1)   odd[jK+e, (j+1)K+e') = w - 2 C_j(e,e'),        C_j(e,e') := #{common c : p_c >= e and q_c < e'}.

**Slot Lemma.** Suppose that to every common letter c of P_j, P_{j+1} a 2-element set Phi_c of integers is assigned
with Phi_c inside [p_c, q_c + 1], such that the sets Phi_c are pairwise disjoint. Then

    (A2)   C_j(e,e') <= max(0, floor((e' - e + 1)/2))     for all e, e'.

*Proof.* If c is counted in C_j(e,e') then e <= p_c and q_c + 1 <= e', so Phi_c lies in the integer interval [e, e'],
which has max(0, e'-e+1) elements; the sets Phi_c are disjoint and have two elements each. QED
(This is slightly more general than the Slot Lemma of the sister proof, where Phi_c = {phi_c, phi_c + 1} with
p_c <= phi_c <= q_c; here one slot, that of 14_1 between P0 and P1, and one between P2 and P3, are not intervals.)

**Slot Table.** By (P) the common types of P_j and P_{j+1} (j <= 2) are those containing j+1 but neither j nor j+2
(two types), and {j, j+2}. The common letters of P3 and the tail are 04_{n+1} and all 03_i (the tail has no letter of
type 13, 14, 23, 24, and of type 04 only 04_{n+1}). Positions from (O):

| pieces | common letter c: (p_c -> q_c), Phi_c |
|---|---|
| P0, P1 | 02_1: (1 -> 1), {1,2};   13_i: (2i+1 -> 2i+1), {2i+1, 2i+2};   14_1: (0 -> 2n+2), {0, 2n+3};   14_i (i>=2): (2i-2 -> 2n+2i), {2n+2i, 2n+2i+1};   02_i (i>=2): (4n+2i-1 -> 4n+2i), {4n+2i, 4n+2i+1} |
| P1, P2 | 02_1: (1 -> 1), {1,2};   13_i: (2i+1 -> 2i+1), {2i+1, 2i+2};   24_i: (2n+2i+1 -> 2n+2i+1), {2n+2i+1, 2n+2i+2};   02_i (i>=2): (4n+2i -> 4n+2i+1), {4n+2i+1, 4n+2i+2} |
| P2, P3 | 03_{n+1}: (0 -> 1), {0,1};   03_i (i<=n): (2i -> 2i+1), {2i, 2i+1};   13_n: (2n+1 -> 4n+5), {2n+2, 4n+5};   13_i (i<n): (2i+1 -> 6n+4-2i), {6n+4-2i, 6n+5-2i};   24_i: (2n+2i+1 -> 2n+2i+1), {2n+2i+1, 2n+2i+2} |
| P3, tail | 04_{n+1}: (0 -> 2), {0,1};   03_i (i<=n): (2i+1 -> 2i+1), {2i+1, 2i+2};   03_{n+1}: (1 -> 2n+3), {2n+3, 2n+4} |

and the sets are pairwise disjoint because they partition the following ranges.
P0,P1: {1..2n+2} (02_1, 13_i), {0, 2n+3} (14_1), {2n+4..4n+3} (14_i, i = 2..n+1), {4n+4..6n+3} (02_i, i = 2..n+1).

P3,tail: {0,1}, {3..2n+2}, {2n+3, 2n+4}.
So (A2) holds for j = 0, 1, 2, 3. [test_slots.py (2), (3)]

**Corollary A (adjacent pieces).** For p = jK+e, p' = (j+1)K+e' as above the path property holds for the window [p,p').

(In particular two occurrences of a letter are at least K-1 positions apart.) [test_slots.py (4), (5)]

## 5. Non-adjacent pieces: S >= -1 (S >= -3 for P0 and the tail)

**Proposition B.** For j' >= j+2, i.e. the pairs (0,2), (0,3), (1,3) and the tail pairs (0,4), (1,4), (2,4), all
0 <= e < K and all e' (0 <= e' < K, resp. 0 <= e' <= 2n+4 for j' = 4):

    S_{jj'}(e,e') >= -1,      and for (j,j') = (0,4):   S_{04}(e,e') >= -3.

The proof evaluates formula (S) on each pair of zones. Local coordinates: (z; a, b) for e in P_j and (z'; A, B) for
e' in P_j' (capital letters for the END prefix, also in the tail). Both satisfy (E) of their zone.

**Rules for the terms.** n_tau = |I symdiff I'| is computed from the two State Table entries by:

* (R1) two initial segments: |{1..p} symdiff {1..P}| = abs(p - P) (written P if p = 0, "full - P" if {1..p} is full).
* (R2) an initial segment {1..p} of a big type (0 <= p <= n+1) in split form: ⟨{1} if p >= 1; {2..cl(p)}; {n+1} if p >= n+1⟩.
* (R3) two split forms ⟨c1; {2..q}; c2⟩, ⟨C1; {2..Q}; C2⟩: n_tau = [c1 != C1] + abs(q - Q) + [c2 != C2]
  (the three parts live in the disjoint ranges {1}, {2..n}, {n+1}; a part that is equal on both sides is omitted, and
  abs(q - Q) is written q - 1, Q - 1, n - q, n - Q if the other side is 1 or n).
* (R4) {1..p} against top(s) (both inside {1..n}): n_tau = p + s - 2 pos(p + s - n)  (the two sets overlap in
  pos(p + s - n) indices); = n - s against the full set.

terms.py applies these rules mechanically to the State Table; the resulting strings are printed below, evaluated on
the words by test_rows.py (each term against the true |I symdiff I'| for every pair of prefixes) and evaluated
symbolically by derive.py.

**The case tables.** For every zone pair, the table lists cases. Each case is a conjunction of linear conditions in
n, a, b, A, B; on the case, S equals the linear form in column "S" (on the case, the conditions together with (E)
decide every bracket [..], abs, pos, min, max, cl occurring in the terms that matters for the sum), and the last column
is a **certificate** for the bound: S - lb written as a sum of multiples (1 or 2) of expressions that are >= 0 on
the case. Every bracketed expression (g) in a certificate is either a domain fact of (E) for the start zone
[(b), (a-b), (-a+b+1), (n-b) resp. (n-b-1)] or the end zone [(B), (A-B), (-A+B+1), (n-B) resp. (n-B-1) resp.
(n-A+2)], or (n-1), or a condition of the case (a condition "x >= y" contributes (x-y); "x <= y" contributes (y-x);
"x = y" both). So each line is checked by expanding one linear identity.

How the tables were made (derive.py): S is evaluated symbolically; whenever a comparison is not decided by the facts
collected so far, the case is split into f >= 0 and f <= -1 (integers!). This gives a binary split tree whose leaves
cover every integer point by construction; on each leaf S is one linear form. Leaves are then enlarged by dropping
conditions as long as the enlarged case meets no leaf with a different linear form. "Decided", "meets no leaf" and the
bounds are established by exact Farkas certificates (rational arithmetic); floating-point LP is only used to find them.

## 6. Proof of the Theorem

Let 0 <= s < p <= L, s = jK+e, p = j'K+e' in the unique representation of Section 2 (so j <= j'; e < K or j = 4).

* j = j': the window lies inside one piece or inside the tail, whose letters are pairwise distinct by (P). So
  odd[s,p) = p - s, and both conditions hold (if p - s >= k then odd = p - s >= k).
* j' = j+1 (including j = 3, j' = 4): Corollary A (Section 4).
* j' >= j+2: the window has length (j'-j)K + e' - e >= 2K - (K-1) = K+1 > k, so we must show odd[s,p) >= k = K-1.
  By the Near-Simplex Lemma odd[s,p) = D_jj' + S_{jj'}(e,e'). For (j,j') != (0,4): D = K and S >= -1 by Proposition B.
  For (j,j') = (0,4): D = K+2 and S >= -3. QED

**Height function** (summary; this is the function a Lean proof would use): for s = jK+e <= p = j'K+e',

    odd[s,p) = p - s                               if j' = j,
             = K - e + e' - 2 C_j(e,e')            if j' = j+1      ((A1); C_j = count from the position table (O)),
             = D_jj' + S_{jj'}(e,e')               if j' >= j+2     (S = the linear form of a matching case of Section 5).

[test_theorem.py: this function equals odd[s,p) for ALL 0 <= s <= p <= L, n = 1..10, and the path property holds.]

## 7. Small n; tightness; what is and is not proved

* **All n >= 1 are covered uniformly; there is no n0 > 1 and no separately verified small case.** n >= 1 enters as the
  fact (n-1) >= 0 in some certificates. At n = 1 several ranges are degenerate (zone 2 has two offsets, small types
  have one index, cl(x) = 1, column conditions like "m < n-1" are void); the definitions, the State Table and the rules
  remain literally valid, and n = 1, 2 are part of every test (n = 1..10). (The word itself is also checked by the
  definition for n = 1..20: `python3 pfam3.py 20`.)
* **Tightness.** The bound of Proposition B (S = -1, resp. S = -3 for the pair (0,4), i.e. odd = k exactly) is attained
  in 32 of the 36 zone pairs (all except (0,2):(0,1), (1,3):(2,0), (1,3):(2,1), (2,4):(2,T)), in 105 cases; and every
  stated case bound lb is attained on the words n <= 10 (test_rows.py prints this), so no case has slack to trade.
* **Kind of evidence per step** (nothing in the Theorem is left open, but the steps are not all of the same kind):
  1. Sections 1-4 and 6 and the rules (R0)-(R4) are hand arguments, uniform in n, each tested on the words n = 1..10.
  2. The State Table derivation (Section 3) is written out per piece; it is tested for every prefix, n = 1..10.
  3. The term strings of Section 5 are produced by terms.py from the State Table by (R1)-(R4) (mechanical; tested
     against the words term by term).
  4. The case tables of Section 5 were found by a program (derive.py), not by hand. The bounds (certificates) and the
     exhaustiveness are re-verified in exact arithmetic for all n by an independent script (test_cert.py (1), (1b)).
     The statement "S equals the listed linear form on the case" is verified exactly for all n only inside derive.py
     (same program that produced it); independently it is verified numerically for n <= 40 (all local coordinates) and
     on the words for n <= 10, and each instance is a short hand computation (as in the reading example). A reader who
     wants a proof free of any trust in derive.py has to do these 343 substitutions (or formalize them, Section 8).
* **Not addressed:** optimality of the length 26n+20 (not part of this document), other families, other parameters.

## 8. Lean plan

Existing infrastructure (ccformal): `cnt T s w c`, `oddc T s w`, `IsPathWord k L T`, PathWalk.lean
(`oddc_snoc_up/down`, `isPathWord_of_walk`, `isPathWord_of_height`, `cnt_three`), the two earlier families
(PathFamEven*.lean, PathFamOdd*.lean) and the plan of PROOF_family_excess.md Section 8, which applies verbatim
with the changes below.

Recommended route: **`isPathWord_of_height`** with the explicit H of Section 6 and a down-step predicate from the
position table. (test_theorem.py checks exactly the three hypotheses in this form: dn from the position table only,
H(s,x+1) = H(s,x) -+ 1, H(s,x) >= K at down-steps.)

* **L1 word.** `fam3T n : ℕ → ℕ` by cases on piece (p / K, with p >= 4K = tail), zone, parity and the exceptional
  columns = the zone-column table of Section 1. Coordinate number = base(type) + (i-1) with base as in pfam3_raw.py
  (types in the order 01 02 03 04 12 13 14 23 24 34, sizes n+1 / n). K = 6n+4, k + 1 = K, L = 26n+20; n = ν + 1 or
  hypothesis `1 ≤ n`. One evaluation lemma per table entry (simp + omega).
* **L2 occurrence lemmas** = position table (O): `fam3T p = coord ↔ p ∈ {..}` for p < L. Occurrences per coordinate:
  four: 02_1 (P0, P1, P2, tail), 13_i (P0..P3), 03_i for all i <= n+1 (P0, P2, P3, tail); three: 02_i (i >= 2), 14_i,
  24_i, 12_i (P0, P2, tail), 04_{n+1} (P0, P3, tail); two: 04_i (i <= n), 23_i, 01_1 (P1, tail); one: 01_i (i >= 2),
  34_i. (Total 26n+20 = L.) A `cnt_four` lemma (copy of `cnt_three`) is needed.
* **L3 sign table.** `dn s x` for x with letter c and earlier occurrences p1 > p2 > p3 of c:
  `dn s x ↔ (p2 < s ∧ s ≤ p1) ∨ s ≤ p3`; one row per entry of (O).
* **L4 height function.** Same piece: `p - s`. Adjacent: `K - e + e' - 2*C_j e e'`; closed forms for C_j are NOT in
  this document (only the count from (O), positions.C); they have to be written as in PROOF_family_excess.md (C01)..(C34) from
  the Slot Table rows (each row is an interval of even or odd offsets plus isolated letters) -- about 15 summands in
  all; the python twin must be added to positions.py and tested first. Non-adjacent: `D + S`. Two options for S:
  (a) the closed forms of the terms (State Table entries as functions of the local coordinates, rules (R1)-(R4)),
  i.e. S := signed sum of the term strings of Section 5 -- 36 definitions by zone pair; or (b) the piecewise linear
  forms of the 343 cases. (a) is shorter to state; then each case of Section 5 is a lemma "conditions → S = linear
  form" (`simp [..]; omega` after `split_ifs`), and each bound is `linarith`/`omega` with the certificate as hint
  (the multipliers are in cases.json; all are 1 or 2, at most 4 conditions per case).
* **L5 step and need lemmas** (`hup`, `hdown`): `H s (x+1) = H s x ± 1` according to `dn s x`, and
  `dn s x → K ≤ H s x`. With option (a): appending the letter at offset e' changes exactly one term by one (the
  index set of one type gains one index); zone and piece boundaries are separate goals where two State Table rows must
  agree (r' = last offset of a zone → next zone; e' = K-1 → next piece). The need lemma is weaker than Proposition B
  ("S ≥ lb+1 whenever the next letter lowers S").
* **L6** `fam3_isPathWord : 1 ≤ n → IsPathWord (6*n+3) (26*n+20) (fam3T n)` by `isPathWord_of_height`.

Second route (closer to this proof): formalize the Near-Simplex Lemma (oddc as a sum over types; parity of cnt of a
coordinate in [jK+e, j'K+e') from its occurrences; the State Table as `Finset.card` statements), then Proposition B =
36 zone-pair lemmas by `omega` and the Slot Lemma = one injection lemma (`Finset.card_le_card_of_injOn` into [e, e'],
two elements per letter; here Phi_c need not be an interval). As for the sister family, route 1 is expected to be
faster because it reuses the pattern of PathFamOdd*.lean.

Risk list for the formalizer: (i) the split form / top(s) entries (five + one) need their own `Finset` lemmas if the
second route is taken; (ii) n = 1 makes several index ranges empty -- state every lemma with `1 ≤ n` only and let
omega handle it, do not special-case; (iii) the pair (0,4) has D = K+2, not K; (iv) the tail has 2n+5 vertices
(e' = 0..2n+4, the last one is the end of the path).

Script twins for the Lean definitions: states.py (State Table), positions.py (position table, slots, C_j), terms.py
(term strings), cases.json (cases, linear forms, certificates), test_theorem.py `H` (height function).
